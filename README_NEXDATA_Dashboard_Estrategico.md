# NEXDATA – Dashboard IA del Plan Estratégico

Actividad adicional e independiente de la aplicación comercial de NEXDATA.

## Ejecutar
1. Instala dependencias: `pip install -r requirements.txt`
2. Ejecuta: `streamlit run app.py`

## Contenido
- Modelo de negocio (Business Model Canvas)
- Visión, misión, cultura y valores
- Herramientas de dirección estratégica
- 4 funciones de la gestión
- 4 objetivos estratégicos: Marketing, RR. HH., Finanzas y Operaciones/Logística
- Metas, KPI, fórmulas, acciones y entregables
- Cronograma visual
- Presupuesto
- Simulación de KPI
- Análisis estratégico IA basado en los valores del dashboard
